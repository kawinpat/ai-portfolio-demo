# AI-Assisted Nuxt 4 Portfolio

## Technology

- Nuxt 4
- Vue 3
- TypeScript
- Composition API

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Route to Company demo

`/route-to-company` uses Nuxt Server API and Google Routes API. Copy `.env.example` to `.env` for local development. Never commit real API keys.

## Purpose

This project documents an AI-assisted software-development workflow: AI tool selection, task, supplied context, AI output, developer validation, and result. The OceanLine Shipping Rate Agent is included as a standalone existing interactive prototype under `public/demos/`.
